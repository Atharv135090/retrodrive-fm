No analytics scripts load and no fake data is shown until real GA4 credentials are added. To connect:

  1. Create a GA4 property for the site in Google Analytics and note the numeric Property ID.
  2. In Google Cloud Console, create an OAuth 2.0 Web Client ID (authorized origin: your site domain; authorized redirect URI: https://<your-site>/).
  3. Enable the Google Analytics Data API for that Cloud project.
  4. Grant the owner’s Google account Viewer access to the GA4 property.
  5. Paste the Property ID and Client ID into js/ga-api.js.
